# ChatGPT Visual & Image Shortcuts

Useful slash-style prompts for turning learning content into images, diagrams, and visual study materials.

> Use these shortcuts before a topic, concept, notes, or pasted content to request a specific visual representation.

---

| Shortcut | What it does |
|---|---|

| `/stickynotes` | Create a sticky-note style visual summary. |

| `/mindmap` | Create a hierarchical mind map of the topic. |

| `/infographic` | Create an infographic summarizing key information. |
| `/timeline` | Visualize events, history, milestones, or sequences over time. |

| `/flashcards` | Turn study material into visual flashcards. |

| `/comic` | Explain a concept using a comic or visual story. |
| `/sketchnotes` | Turn content into sketch-note style learning notes. |
| `/whiteboard` | Present an explanation like a classroom whiteboard. |
